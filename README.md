MKPANE WEBSITE PROJECT

WEDE 5020 – Web Development

Part 1 and Part 2

1. Project Overview

The MKPANE Website Project is a web development project created as part of the WEDE 5020 Web Development module at Rosebank College.

The purpose of this project is to design and develop a professional, informative and user-friendly website for MKPANE, an agricultural organisation focused on quality agricultural production, sustainable farming practices and community development.

The website provides visitors with information about the organisation, its services and its business activities. It also allows potential customers and interested parties to make enquiries and contact the organisation.

The project demonstrates the application of fundamental web development technologies, including HTML5 and CSS3.

2. Project Objectives

The main objectives of the MKPANE website are:

Establish an online presence for MKPANE.
Introduce visitors to the organisation and its purpose.
Present the agricultural services offered by the organisation.
Provide clear navigation between website pages.
Allow visitors to submit enquiries through an enquiry form interface.
Provide contact information and communication options.
Create a professional and visually appealing website.
Apply web development principles learned during the WEDE 5020 module.

3. Website Structure

The website consists of five main pages.

3.1 Home Page (index.html)

The home page introduces MKPANE and communicates the organisation's vision and purpose.

It includes:

Website branding and navigation.
Welcome section.
Introduction to MKPANE Agriculture.
Overview of the organisation's main activities.
Links directing visitors to other website sections.

3.2 About Us Page (about.html)

The About Us page provides information about MKPANE, its background, purpose and organisational direction.

It helps visitors understand the organisation and its commitment to agricultural development.

3.3 Services Page (services.html)

The Services page presents the agricultural services and activities associated with MKPANE.

These include:

Agricultural production.
Fresh produce.
Farming support.
Sustainable agriculture.
Agricultural partnerships.
Business growth opportunities.

3.4 Enquiry Page (enquiry.html)

The Enquiry page provides an interface where visitors can enter their details and submit questions about the organisation's services.

The form includes fields for visitor information, enquiry categories and messages.

The enquiry form is part of the website interface. Back-end form processing is not included in this project stage.

3.5 Contact Page (contact.html)

The Contact page provides visitors with a way to find contact information and communicate with MKPANE.

It supports the website's objective of making communication between the organisation and potential customers easier.

4. Technologies Used

The following technologies and development tools were used:

HTML5

Used to create the structure and content of the website.
Organises headings, paragraphs, navigation, forms and sections.

CSS3

Used to style the website.
Controls colours, layouts, typography, spacing and responsive design.

JavaScript

Not required for the initial HTML and CSS foundation documented in Parts 1 and 2.

Visual Studio Code / NetBeans

Development environments used for working with website files.

Git and GitHub

Used for version control and maintaining the project repository.
GitHub provides an online location for storing and managing project files.

GitHub Pages

Used to publish the website online.

5. Website Design and Layout

The website uses a consistent visual identity based on a natural agricultural theme.

The main design elements include:

Dark green as the primary brand colour.
Light green accents.
White backgrounds and content sections.
Agricultural imagery.
Clear headings and readable typography.
Consistent navigation across the website.
Responsive layouts for different screen sizes.

The design aims to create a professional appearance while reflecting the agricultural identity of MKPANE.

6. Navigation and User Experience

The website includes a navigation menu that allows visitors to move between the five main pages.

Navigation links include:

Home
About Us
Services
Enquiry
Contact

Buttons and links are included throughout the website to guide visitors towards relevant information and enquiry sections.

Responsive CSS styling is also used to improve the website's presentation on smaller screens.
